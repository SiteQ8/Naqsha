Diagrams as code. Describe a system as nodes, edges, and groups on the left, and get a polished interactive diagram on the right: pan and zoom, click a node to trace everything it reaches upstream and downstream, search, switch theme, and export a clean SVG or PNG. The command line turns the same source into one self contained HTML file you can open anywhere. Nothing you type here leaves your browser.
